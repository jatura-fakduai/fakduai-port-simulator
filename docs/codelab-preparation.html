สร้าง LINE Official Account

  1. เปิดลิงก์สมัครบัญชีทั่วไป (ฟรี)
    https://entry.line.biz/form/entry/unverified
    เปิดหน้าสมัคร ↗
  2. ระบบจะพาไปหน้า LINE Business ID › Login ก่อน ให้กด LINE account (ปุ่มสีเขียว)
  3. หน้า QR code login จะขึ้นมา เปิดแอป LINE บนมือถือ กดไอคอนสแกน QR ข้างช่องค้นหา แล้วสแกน QR บนจอ ถ้าเคยผูกอีเมลไว้ในแอป LINE จะกด Log in with email แทนก็ได้
  4. ล็อกอินเสร็จจะเข้าหน้า สร้าง LINE ออฟฟิเชียลแอคเคาท์ กรอก ชื่อบัญชี (ไม่เกิน 20 ตัวอักษร เป็นชื่อที่ลูกค้าเห็น), อีเมล และเลือก ประเภทธุรกิจ ทั้งหลักและย่อย ส่วนชื่อบริษัทไม่บังคับ
  5. เลื่อนลงล่าง แล้วกด ตกลง (เท่ากับยอมรับข้อกำหนดการใช้บริการ)
  6. หน้า ตรวจสอบรายละเอียด เช็กข้อมูลให้ถูก แล้วกด เสร็จสิ้น
  7. ขึ้นข้อความ สร้าง LINE ออฟฟิเชียลแอคเคาท์แล้ว พร้อม เบสิค ID (เช่น @941duujo) บัญชีนี้จะถูกเพิ่มเป็นเพื่อนใน LINE ของคุณอัตโนมัติ กด ไป LINE Official Account Manager
ใช้บัญชี LINE เดิมตลอด ทุกขั้นที่ต้องล็อกอินเข้า OA Manager และ LINE Developers ต้องใช้บัญชีเดียวกับที่สมัครในขั้นนี้

เปิดใช้ Messaging API

Messaging API คือช่องทางที่ให้ n8n รับและส่งข้อความแทนแอดมิน

  1. เข้า OA Manager ครั้งแรกจะเจอ ข้อตกลงเกี่ยวกับการใช้ข้อมูล อ่านแล้วกด ยอมรับ
  2. หน้าต่าง ยินดีต้อนรับ (1/2) กด ต่อไป แล้วในหน้า (2/2) กด ไปหน้าหลัก
  3. กด ⚙ ตั้งค่า ที่มุมขวาบน
  4. ที่เมนูซ้าย กด Messaging API
  5. สถานะยังเป็น "ไม่ใช้งาน" กด ใช้ Messaging API
  6. หน้าต่าง เลือกโพรไวเดอร์ เลือก สร้างโพรไวเดอร์ แล้วตั้งชื่อ (เช่น ai-logistics-provider) หรือเลือกโพรไวเดอร์เดิมที่มีอยู่ แล้วกด ยอมรับ
  7. หน้าต่าง นโยบายความเป็นส่วนตัวและข้อกำหนดการใช้บริการ ทั้งสองช่องไม่บังคับ ปล่อยว่างได้ แล้วกด ตกลง
  8. หน้าต่างยืนยัน ใช้ Messaging API เช็กชื่อบัญชีกับชื่อโพรไวเดอร์ แล้วกด ตกลง
  9. สถานะเปลี่ยนเป็น กำลังใช้งาน และได้ แชนแนล ID มา
โพรไวเดอร์เปลี่ยนภายหลังไม่ได้ ในหน้าต่างยืนยันจะเตือนว่าเชื่อมต่อแล้วแก้ไขหรือยกเลิกไม่ได้
